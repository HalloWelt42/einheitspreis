# Datenschutz

Einheitspreis liest nur die gerade geöffnete Shopseite im Browser und rechnet dort. Es werden keine Daten gesendet, keine Anfragen an fremde Server gestellt, keine Nutzung erfasst.

Gespeichert wird lokal im Browser nur die Einstellung (Speicher pro TB oder GB, Liste offen oder zu). Entfernen der Erweiterung löscht sie.
